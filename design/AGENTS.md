# Figma Website Design for Loom

This directory contains the Figma-generated UI prototype and visual reference implementation for the Loom Developer Cockpit.

## Structure
- `src/App.tsx`: Interactive preview of all core screens (Overview, Findings, Impact Graph, Verification, Reports, Settings).
- `src/index.css`: Obsidian & Zinc design tokens, typography, and layout rules.
- `src/main.tsx`: React DOM mount.
- `public/favicon.svg`: Diagnostic plate mark with ember fault line.
