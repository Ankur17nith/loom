# Reproducible Loom demo

This demo creates a temporary Git repository, commits a `UserResponse` contract
and consumer, removes `name` from the contract, and asks Loom to analyze the
working tree. It does not touch the current repository or execute any command
from the temporary repository.

From the Loom root after building:

```bash
npm ci
npm run build:cli
bash scripts/demo-contract-impact.sh
```

Expected evidence includes:

- `src/user.ts` as the changed declaration.
- `src/profile.ts` as the affected consumer.
- A path from `src/profile.ts` to `src/user.ts`.
- A high-confidence removed-field finding.
- Repository-relative file and line locations.

To preview the same report in the dashboard, save a report artifact and serve
it from a static host:

```bash
node dist/cli.js report --base HEAD --format json --output .loom/reports/report.json
VITE_LOOM_REPORT_URL=/reports/report.json npm run dev --workspace apps/dashboard
```

The built-in dashboard fixture is explicitly labeled as demo data. It is not a
substitute for the report generated by the CLI.
